# xCOMET: Transparent Machine Translation Evaluation through Fine-grained Error Detection

- **Authors:** Guerreiro, Rei, van Stigt, Coheur, Colombo, Martins
- **Venue:** TACL 2024
- **ID:** arXiv:2310.10482
- **BibTeX key:** `guerreiro2024xcomet`

## Summary

Neural metric that gives a sentence score and also tags error spans with severities; works with or without a reference.

## Why we cite it

XCOMET-XXL, our main quality metric (used reference-free, as in ALMA-R).
