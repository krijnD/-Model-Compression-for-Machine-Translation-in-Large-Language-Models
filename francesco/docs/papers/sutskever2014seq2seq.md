# Sequence to Sequence Learning with Neural Networks

- **Authors:** Sutskever, Vinyals, Le
- **Venue:** NeurIPS 2014
- **ID:** arXiv:1409.3215
- **BibTeX key:** `sutskever2014seq2seq`

## Summary

Introduces the LSTM encoder-decoder for MT: an encoder maps the source sentence to a vector and a decoder generates the target from it.

## Why we cite it

Origin of the encoder-decoder paradigm for neural MT.
