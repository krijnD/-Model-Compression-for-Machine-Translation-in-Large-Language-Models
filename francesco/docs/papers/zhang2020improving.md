# Improving Massively Multilingual Neural Machine Translation and Zero-Shot Translation

- **Authors:** Zhang, Williams, Titov, Sennrich
- **Venue:** ACL 2020
- **ID:** arXiv:2004.11867
- **BibTeX key:** `zhang2020improving`

## Summary

Identifies off-target translation (output in the wrong language) as a main failure of multilingual NMT and measures it with language identification.

## Why we cite it

Name and measurement for our 'off-target' failure category.
