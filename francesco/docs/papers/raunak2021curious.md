# The Curious Case of Hallucinations in Neural Machine Translation

- **Authors:** Raunak, Menezes, Junczys-Dowmunt
- **Venue:** NAACL 2021
- **ID:** arXiv:2104.06683
- **BibTeX key:** `raunak2021curious`

## Summary

Studies hallucinations in NMT and names the oscillatory type: outputs that repeat the same n-grams. Detects it with top n-gram count (TNG): the most repeated n-gram of the output occurs much more often than that of the source.

## Why we cite it

Name and detector for our 'oscillation' failure category (TNG, 4-grams, threshold 2).
