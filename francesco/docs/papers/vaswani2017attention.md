# Attention Is All You Need

- **Authors:** Vaswani et al.
- **Venue:** NeurIPS 2017
- **ID:** arXiv:1706.03762
- **BibTeX key:** `vaswani2017attention`

## Summary

Introduces the Transformer, an encoder-decoder built only from attention. It became the standard NMT architecture.

## Why we cite it

Transformer encoder-decoder; the architecture under both NLLB and LLaMA.
