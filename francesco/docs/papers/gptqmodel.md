# GPTQModel (software library)

- **Authors:** ModelCloud
- **Venue:** GitHub, https://github.com/ModelCloud/GPTQModel
- **Version used:** 4.2.5 (`venv-quant`)
- **BibTeX key:** `gptqmodel`

## Summary

Library for GPTQ quantization and inference of Hugging Face LLMs; successor of AutoGPTQ. Packs weights into int32 checkpoints and provides inference kernels (Torch, Triton, ExLlamaV2 for 4 bits).

## Why we cite it

Tool used to quantize ALMA-13B-R and to run the quantized checkpoints.
