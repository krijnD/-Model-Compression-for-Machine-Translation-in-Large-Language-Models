Project 4: Model Compression for Machine Translation in Large Language Models.

Project description: This project explores the application of model compression techniques specifically for machine translation (MT) tasks in ALMA Links to an external site.large language models (LLMs). The objective is to reduce the model size and computational requirements while maintaining high translation quality. You are expected to implement compression techniques such as Quantization, Pruning, and Knowledge Distillation to reduce the model size while maintaining translation quality as much as possible. Note that you could make use of the ALMA training data for any purpose like Distillation or fine-tuning (both PEFT and fully finetuning are allowed).
