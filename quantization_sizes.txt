2. WHAT SHRANK, AND THE FLOOR
--------------------------------------------------------------------

Quantized: the 12,588,646,400 params of all 40 decoder layers' Linears
           (self_attn q/k/v/o_proj, mlp gate/up/down_proj)  =  23.45 GiB in fp16.
  w8g128   11.92 GiB  ->  1.97x on the quantized region alone
  w4g128    5.96 GiB  ->  3.93x on the quantized region alone
  w3g128    4.47 GiB  ->  5.24x on the quantized region alone
  w2g128    2.98 GiB  ->  7.86x on the quantized region alone

Frozen in fp16 in every run: 0.796 GiB
  embed_tokens + lm_head (2 x 163.84 M = 625 MiB) + RMSNorms + fp16 scales/zero-points
  (98.35 M groups of 128 = 187.5 MiB). This floor never shrinks, so the end-to-end
  ratios saturate: this recipe tops out near 31x even at zero bits for the Linears.

Effective bits (8.13 / 4.07 / 3.05 / 2.04) exceed the nominal ones only by scale,
zero-point and g_idx overhead - no packing slack. Verified from qweight shapes per
5120x5120 tensor: [1280,5120]=4 / [640,5120]=8 / [480,5120]=10.67 / [320,5120]=16
values per int32, i.e. exactly 8 / 4 / 3 / 2 bits per weight.

3. CALIBRATION
--------------------------------------------------------------------

Examples   : 1024 (balanced over the 10 directions: 103 for the first 4 pairs, 102 for the rest)
Tokens     : 104,925 total, ~102 per example (max_length 512, truncated)
Data       : ALMA's human-written parallel TRAIN files,
             third_party/ALMA/human_written_data/<xx>en/train.<xx>-en.json
             (earlier WMT test sets + Flores). Train split only -> zero overlap with
             the WMT'22 (WMT'21 for is) test sets that are being scored.
Directions : de-en,cs-en,is-en,zh-en,ru-en,en-de,en-cs,en-is,en-zh,en-ru
Sampling   : random.Random(42).sample per direction, then shuffled with the same seed
Format     : ALMA fine-tuning format, <s> + prompt + target + </s>, where prompt is
              'Translate this from {SRC} to {TGT}:\n{SRC}: <source sentence>\n{TGT}:'
Tokenizer  : ALMA's own (add_eos_token=False); truncate to max_length-1, then append eos_token_id
Batch size : 1 per forward pass (GPTQModel logs samples=104,925 per layer)

4. QUANTIZATION SETTINGS (identical across the four runs)
--------------------------------------------------------------------

group_size=128  sym=false (asymmetric, zero-points)  desc_act=true (act-order)
damp_percent=0.05  true_sequential=true  static_groups=false
pack_dtype=int32  checkpoint_format=gptq  lm_head=false (kept fp16)
quantize time: 16.6 / 16.6 / 16.5 / 16.5 min (w8 / w4 / w3 / w2), one GPU

Provenance: quant_meta.json + quantize_config.json + quant_log.csv in each checkpoint
directory. w8 was quantized first (finished 12:29); w2/w3/w4 ran in parallel at 14:33
and finished 14:49-14:50 - all four report the same 104,925 calibration tokens. Earlier
logs with samples=3730 are superseded iterations, not the shipped checkpoints.
